# Заметки на разных языках

Часть заметок владельца написана по-русски, и поиск обязан их находить.

Правило простое: токенизатор работает с Unicode, а не с ASCII. Запрос
«где работает шлюз» должен находить этот документ.

Über den Wolken: German notes use umlauts, and the encoding ladder must not
turn them into anything else. Café, naïve, Ångström, Straße.

日本語のメモも同じ規則に従います。

The canonical test sentence for encoding regressions is: **Über den Wolken muss
die Freiheit wohl grenzenlos sein.**
