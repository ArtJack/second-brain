# The agent contract

Orient, plan, test first, verify, report. A behaviour change gets its test
written before the change.

Never accept a subagent's success claim without evidence. Self-reported "done"
is not done; output excerpts and spot-checked file paths are.

A pass verdict without a stated "not tested" list is incomplete and goes back.
A blocked verdict is the caller's to clear, not something to re-ask for a pass on.
